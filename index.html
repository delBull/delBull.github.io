GTA Sin Consola

Herramienta interna de edición y publicación para un canal de YouTube.

Esta aplicación es una utilidad de escritorio que el operador del canal GTA Sin Consola ejecuta en su propio equipo para preparar clips y programar sus publicaciones. No es un servicio abierto al público, no tiene registro de usuarios y no recibe datos de terceros.

Qué hace

  • Procesa localmente material de video que el propio operador ya posee o tiene licencia para usar.
  • Genera cortes verticales con subtítulos y los deja listos para revisión.
  • Se conecta a la cuenta de YouTube del operador, mediante el consentimiento OAuth de Google, para subir y calendarizar esos videos.
  • Consulta las estadísticas del propio canal para mostrar cuánto falta para los requisitos de monetización.

Qué no hace

  • No procesa datos de espectadores ni de otros usuarios de YouTube.
  • No envía información a servidores propios: no existe backend ni base de datos remota.
  • No vende, comparte ni usa datos para publicidad o perfilado.

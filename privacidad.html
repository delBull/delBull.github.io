GTA Sin Consola

Política de Privacidad

Última actualización: 14 de noviembre de 2026

Esta política describe cómo la herramienta de publicación del canal GTA Sin Consola (en adelante, «la Aplicación») trata la información a la que accede. La Aplicación es una utilidad de escritorio de uso privado: la ejecuta únicamente el operador del canal, en su propio equipo.

1. Quién opera la Aplicación

La Aplicación es operada por el responsable del canal de YouTube «GTA Sin Consola». Contacto para cualquier asunto de privacidad: knockoutmediamexico@gmail.com.

2. Qué información se obtiene de Google

Previa autorización expresa del operador mediante el flujo OAuth de Google, la Aplicación solicita tres permisos, todos ellos sobre la propia cuenta de YouTube del operador:

  • youtube.upload — subir videos a la cuenta del operador.
  • youtube — gestionar metadatos de esos mismos videos (título, descripción, etiquetas, visibilidad).
  • yt-analytics.readonly — leer estadísticas del canal del operador (vistas, retención, suscriptores).

La Aplicación no solicita acceso a Gmail, Contactos, Drive, Calendario ni a ninguna otra cuenta de Google.

3. Dónde se almacena la información

El token de acceso se guarda únicamente en el disco local del equipo del operador, en el archivo config/token.json. Las estadísticas del canal se guardan en data/stats.json, también localmente.

  • No existe servidor, base de datos remota ni backend propio.
  • La información no se transmite a terceros, ni se vende, ni se comparte.
  • No se usa para publicidad, perfilado, scoring crediticio ni entrenamiento de modelos.
  • No se recopilan datos de espectadores ni de otros usuarios de YouTube.

4. Uso limitado de datos de Google

El uso que la Aplicación hace de la información recibida de las API de Google cumple con la Política de Datos de Usuario de los Servicios API de Google, incluidos los requisitos de Uso Limitado (Limited Use). Los datos obtenidos solo se emplean para las funciones descritas en esta política.

5. Conservación y eliminación

El token permanece en el equipo hasta que el operador lo revoca o lo borra. Para revocar el acceso en cualquier momento:

  • En Google: myaccount.google.com/permissions → seleccionar la Aplicación → «Quitar acceso».
  • En el equipo: eliminar el archivo config/token.json.

Al revocar el acceso, la Aplicación deja de poder leer o modificar la cuenta de YouTube. Los videos ya publicados permanecen en el canal, bajo control del operador.

6. Seguridad

El token se mantiene en un directorio local del equipo del operador, sin exposición pública. La Aplicación no transmite credenciales a ningún servicio distinto de los servidores de Google.

7. Menores de edad

La Aplicación no está dirigida a menores y no recopila información de ninguna persona distinta del propio operador.

8. Cambios a esta política

Cualquier cambio se publicará en esta misma página, actualizando la fecha del encabezado.

Summary in English

This is a private desktop utility used by the operator of the «GTA Sin Consola» YouTube channel to edit and publish his own videos. It requests only youtube.upload, youtube and yt-analytics.readonly scopes on the operator's own account. OAuth tokens and channel statistics are stored locally on the operator's machine; there is no server, no third-party sharing, no advertising and no profiling. The use of Google API data adheres to the Google API Services User Data Policy, including Limited Use requirements. Revoke access at myaccount.google.com/permissions. Contact: knockoutmediamexico@gmail.com.
